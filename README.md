# Planfeto 2.0

Sistema web para controle de entregas desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Login demonstrativo
- Dashboard com total de entregas
- Cadastro de novas entregas
- Listagem de entregas
- Edição de entregas
- Exclusão de entregas
- Atualização de status
- Simulação de envio de comprovante por foto
- Mapa de circulação usando Leaflet e OpenStreetMap

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Leaflet

## Objetivo

O projeto foi desenvolvido para simular o controle de entregas de uma empresa, permitindo cadastrar pedidos, acompanhar status, visualizar indicadores e registrar uma entrega como finalizada.

## Observações

Este projeto utiliza LocalStorage para simular persistência de dados no navegador. Em uma versão real, o sistema poderia ser integrado a uma API com banco de dados e autenticação segura.

## Melhorias futuras

- Login com autenticação real
- Upload real de fotos
